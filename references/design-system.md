# Ellen 设计系统——基于原作品提取的规范

本系统提取自 Ellen 的 AI 产品经理作品集，将研究田野笔记、编辑式版面、产品证据与克制的手工拼贴语言结合在一起。

## 1. 品牌核心

**具有产品严谨性的田野笔记。** 表层温暖、有人情味并保留探索感；底层信息结构清晰，有编号、可验证，并明确展示判断依据。触感手工艺与分析清晰度之间的张力，是这套系统最重要的辨识度。

性格关键词：周到、温暖、证据导向、好奇、跨学科、略带趣味，但不为了可爱而可爱。

## 2. 色彩 Token

| 角色 | Token | 色值 | 用途 |
|---|---|---:|---|
| 主纸张色 | `paper` | `#F5F0E7` | 页面底色与温暖留白 |
| 抬升纸张色 | `paper-2` | `#FFFAF0` | 卡片、便签、按钮与照片衬纸 |
| 主墨色 | `ink` | `#20211E` | 正文、边框与深色面板 |
| 次级墨色 | `muted` | `#696861` | 辅助文字与元数据 |
| 细线色 | `line` | `#CFC5B5` | 分隔线、规则线与弱化边框 |
| 分析蓝 | `blue` | `#4D73C8` | 系统、链接、空间与技术内容 |
| 淡蓝底 | `blue-soft` | `#DCE5FF` | 蓝色项目区与高亮 |
| 稳定绿 | `green` | `#637554` | 自然、流程与稳健专业感 |
| 淡绿底 | `green-soft` | `#DFE8D6` | 绿色项目区 |
| 行动珊瑚红 | `coral` | `#E96145` | 行动按钮、批注与主动强调 |
| 淡珊瑚底 | `coral-soft` | `#F7D8CB` | 珊瑚红项目区 |
| 便签黄 | `yellow` | `#F2D977` | 胶带、标签、文字选中与便签卡 |
| 方法论展板 | `board` | `#25332B` | 深绿黑色的教学/流程面板 |

暖色纸张和墨色应占画面的约 75%–85%。强调色应作为小面积的语义区域出现，不要平均分配成彩虹。一个区块通常只设一种主强调色，最多再加入一种辅助强调色。

推荐透明色与背景参数：

- 网格：28 px 方格，1 px 线条，颜色为 `rgba(66,74,66,.055)`。
- 抬升纸张：`rgba(255,250,240,.94)`。
- 暖色柔和阴影：`0 18px 50px rgba(63,48,30,.13)`。
- 硬质错位阴影：使用墨色或当前区块强调色，偏移 2–6 px。

避免纯白页面、纯黑色、饱和渐变、大面积连续强调色、霓虹、光亮金属和冷灰色 UI 调色板。

## 3. 字体系统

除非项目提供了已获授权的字体，否则优先使用系统安全字体。

- 展示/编辑字体：`Georgia, "Times New Roman", "Songti SC", serif`。
- 正文/UI：`ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- 元数据/证据：`ui-monospace, SFMono-Regular, Menlo, monospace`。
- 手写便签：`"Kaiti SC", "STKaiti", cursive`；只用于简短批注。

层级规则：

- 展示级标题：桌面端 48–78 px，移动端 43–68 px；字重 400–600；行高 .98–1.08；字距约 `-.035em`。
- 章节标题：34–62 px；使用衬线字体和紧凑行高。
- 卡片标题：根据场景使用 23–48 px 衬线字体。
- 正文：根据重要程度使用 15–24 px；行高 1.45–1.7。
- 眉题与元数据：10–12 px；大写；字重 700–900；字距 `.07em–.18em`。

有意识地混合中英文：中文承载主要解释；英文适合短小的编辑标签、类别和章节签名。不要把长英文句子当作装饰。

## 4. 布局与节奏

- 内容最大宽度：1180 px。
- 桌面端外边距：至少 20 px；移动端：至少 14 px。
- 吸顶导航高度：桌面端 74 px；移动端 64 px。
- 大章节垂直间距：桌面端约 110 px；移动端约 82 px。
- 采用具有编辑感的双栏比例，如 `1.28fr / .72fr`、`.72fr / 1.28fr` 或 `1.08fr / .92fr`。
- 28 px 网格是背景肌理，不是限制所有对象的布局牢笼。重要对象可以偏离网格几像素。
- 保持充足留白，再让一个拼贴对象跨越网格或轻微倾斜。

长篇内容序列可使用大号、浅色、斜体的章节编号，配合双语眉题与衬线标题。编号采用 `01、02、03……`，传达经过编辑整理的一组作品。

## 5. 形状、边框与阴影

- 卡片：接近直角，圆角控制在 0–4 px，使用 1 px 暖灰边框。
- 胶囊形：仅用于紧凑标签和少量行动按钮。
- 虚线边框：用于便签区、内嵌框、证据边界或折叠控件。
- 圆形：仅用于品牌标记、项目编号徽章和少量印章。
- 旋转：纸张/照片控制在 ±0.2–3°；贴纸或手写批注在有意强调时可达到约 11°。
- 柔和阴影用于制造纸张层次；硬质错位阴影用于产生印刷或印章感。不要在所有元素上同时大量使用两者。

## 6. 拼贴语法

可信的 Ellen 拼贴由明确的功能角色组成，而不是随机添加剪贴簿元素：

1. **基础纸张**——带淡制图网格的象牙色纸面。
2. **主要标本**——放在独立纸张或照片衬纸上的肖像、产品截图、图表或核心信息。
3. **固定线索**——一条半透明黄色胶带、别针、夹子或边框处理。
4. **证据线索**——图注、画面编号、指标条、来源标签或日期便签。
5. **人情线索**——短小的珊瑚红手写批注、水彩个人 IP 或轻微不规则的印章。
6. **编辑框架**——清晰对齐与足够留白，避免画面变成手工材料堆积。

照片衬纸使用 11–18 px 的内边距，并在底部保留更深空间放置图注。图像加 1 px 边框和暖色投影。旋转整张衬纸，不要单独旋转内部内容。

网页尺度下，胶带可参考 92 × 27 px，使用半透明暖黄色、不规则多边形边缘与轻微旋转。胶带的作用是固定对象，不要散落成纯装饰。

批注应短小、使用珊瑚红，并带有方向性。一支小箭头加一句话，通常比多个涂鸦更有力量。

## 7. 组件模式

### 导航

使用暖色半透明纸张、细底部分隔线与轻微模糊。包含黑色有机圆形首字母标记、稳重字标、简短文字链接和一个描边胶囊行动按钮。悬停时，珊瑚红下划线从左向右生长。

### 首屏/封面

左侧放置黄色虚线田野笔记标签、大号衬线自我介绍、直白的价值说明、等宽标签、主次行动按钮和一条手写批注。右侧放置轻微倾斜的水彩肖像卡，搭配胶带、一个珊瑚红印章和一张用别针固定的事实便签。

### 项目案例卡

分为带色视觉区和抬升纸张叙事区。视觉区包含旋转截图衬纸、编号徽章、虚线内框和可选的小型原型按钮。叙事区包含元数据、衬线标题、问题描述、彩色决策说明块和三个精炼证据指标。移动端将视觉区堆叠在叙事区上方。

### 方法论展板

使用深绿黑色展板、暖象牙色文字、黄色步骤编号、四步网格，以及一张附着在展板上方的黄色标签。这是整套系统中对比最强的教学组件。

### 证据卡

先用大号衬线字体展示指标，再放置简短限定说明。多个指标并列时，优先使用顶部规则线，而不是每项都放进独立方框。明确数字属于实测、自评、目标还是观察结果。

### 时间线

使用简洁的竖向墨线、空心圆节点、珊瑚红等宽日期、衬线职位标题和次级墨色说明。宽屏布局中，肖像卡应与时间线分离并保持粘性定位。

### 页脚/联系方式

使用整块墨色背景与纸张色文字，搭配大号衬线邀请语、描边联系卡、黄色线性图标和大写微型文字。收尾应自信而紧凑。

## 8. 图像与插画

优先选择水彩或剪纸感的个人图像、轻微不规则边缘、中性日光，以及作为证据展示的产品截图。可轻微降低饱和度、柔化对比度，不要使用让作品显得陈旧或浑浊的滤镜。

提供的 Chenchen 角色是身份锚点。将其与编辑式结构和事实便签结合，不要用密集的可爱装饰包围它。产品截图必须保持足够清晰，真正承担证明作用。

## 9. 动效与交互

- 默认动效时长：200–700 ms，使用平静的缓动曲线。
- 卡片悬停时可从 1–2° 倾斜恢复水平，并缩放到约 1.015。
- 按钮悬停时可移动 `-2px, -2px`，同时增加 5–6 px 的强调色错位阴影。
- 章节进入时可使用透明度变化与 24 px 纵向位移。
- 保留清晰可见的键盘焦点状态。
- 遵循 `prefers-reduced-motion`：关闭平滑滚动、进入位移和装饰性过渡。

动效应该像在翻动纸张，而不是在播放产品宣传片。

## 10. 无障碍与内容真实性

- 保持符合 WCAG 意识的对比度；不要在浅色底上使用过小的次级墨色文字。
- 网页中的元数据不得小于 10 px；幻灯片和社交媒体导出图中需要更大。
- 装饰性旋转不能让段落或图表难以阅读。
- 即使拼贴在视觉上不对称，DOM 与阅读顺序也必须符合逻辑。
- 为个人 IP 肖像和有意义的截图提供替代文本；胶带与纯装饰痕迹应对辅助技术隐藏。
- 不要编造证据。经过视觉设计的指标仍需保留真实限定条件与来源。

## 11. 禁止模式

- 只有米色极简，却没有网格、证据和人的痕迹。
- 彩虹式剪贴簿堆叠、过量撕纸、大量贴纸或大段手写文字。
- 典型科技视觉：霓虹蓝紫渐变、发光大脑、玻璃卡片和漂浮 3D 图标。
- 过度圆角的 SaaS 卡片与过多胶囊控件。
- 正文过小、对比度过低的高时尚编辑排版。
- 让每个元素都同时倾斜、贴胶带、加边框并投影。
- 把 Chenchen 角色当作随处出现的吉祥物，而不是有意识使用的身份锚点。
