# 使用说明、输入输出与可复制提示词

本页用于第一次调用 `ellen-design-system`、准备设计 Brief，或直接复制一段提示词开始制作。

## 最小输入

只要提供以下三项，就可以开始：

1. **内容或材料**：正文、截图、文档、数据、网页链接或本地文件路径。
2. **产出类型**：海报、社交媒体长图、PPT、网页、文档、简历或产品原型。
3. **传播任务**：受众是谁，以及希望对方看懂、相信或采取什么行动。

为了提高一次成稿率，可以继续补充：

- 尺寸或比例，例如 `1080×1440`、`16:9`、A4。
- 输出格式，例如 PNG、PPTX、PDF、HTML；是否必须可编辑。
- 风格强度：`克制版`、`标准版`、`强拼贴版`。
- 主色：珊瑚红、分析蓝、植物绿或便签黄；未指定时由内容语义决定。
- 必须使用的资产，例如水彩头像、项目截图、品牌标记。
- 禁用元素，例如“不使用头像”“不要过多贴纸”“不要手写字”。
- 输出位置或文件名。

## 默认值

用户没有明确指定时，按以下默认值执行：

- 风格强度使用**标准版**。
- 色彩以暖象牙纸、炭黑为基础，只启用一到两种强调色。
- 每个画面最多一个主要标本对象、一个固定线索和一组批注或印章。
- 优先保障标题、关键信息和证据在实际尺寸与缩略图下可读。
- 不自动使用 Chenchen 水彩人物；只有用户明确要求，或内容确实需要个人身份锚点时才使用。
- 精确文字使用原生排版工具添加；图像生成主要负责纸纹、插画或装饰背景。

## 输出内容

一次完整交付通常包含：

1. **主成品**：用户要求的图片、PPTX、PDF、HTML 或其他文件。
2. **可编辑结构**：用户要求可编辑时，正文、标题、证据卡、图表和核心形状保持独立可编辑。
3. **简短说明**：说明采用的版式方向、主色、风格强度，以及任何重要取舍。
4. **真实性说明**：缺少数据、来源或评测结果时明确标注“待补”，禁止编造指标。
5. **验证**：按媒介检查尺寸、可读性、溢出、文件完整性与最终渲染效果。

## 通用提示词模板

复制后替换方括号中的内容：

```text
使用 $ellen-design-system，把[内容或文件路径]制作成[产出类型]。

受众：[目标受众]
传播目标：[希望对方在多长时间内理解什么，或采取什么行动]
尺寸/比例：[尺寸或比例]
输出格式：[PNG / PPTX / PDF / HTML / 其他]
可编辑性：[必须可编辑 / 导出图片即可]
风格强度：[克制版 / 标准版 / 强拼贴版]
主色：[珊瑚红 / 分析蓝 / 植物绿 / 便签黄 / 自动判断]
必须使用：[指定资产、截图、数据或“无”]
不要使用：[头像、过多贴纸、某种颜色或“无”]

内容：
[粘贴正文，或列出文件路径]

要求：
- 每个画面只表达一个重点；
- 保持标题和证据在实际尺寸及缩略图下清晰；
- 缺失的数据与来源明确标注待补，不要编造；
- 完成后检查尺寸、文字溢出和最终渲染效果。
```

## 可复制示例：小红书长图

```text
使用 $ellen-design-system，把下面的内容制作成一张 1080×1440 的小红书长图。

受众：关注产品设计与社交产品的人
传播目标：让读者在 10 秒内理解“社交是人与人之间的价值交换”
输出格式：PNG
风格强度：强拼贴版
主色：珊瑚红
必须使用：编号章节、证据卡、需求维度展板
不要使用：Chenchen 水彩头像、过多贴纸

内容：
[粘贴文章正文或提供文件路径]

要求：
- 缩略图状态下“何谓社交？”仍然清晰；
- 一张图内只保留一个主标题、一个核心定义和两到三个证据区；
- 纸纹、水彩和胶带只作为层级线索，不遮挡正文；
- 最终检查输出尺寸必须为 1080×1440。
```

完成效果参考：[`../assets/example-xiaohongshu-social.png`](../assets/example-xiaohongshu-social.png)。该图用于理解信息层级与拼贴强度，不要求逐像素复刻。

## 可复制示例：5 页项目汇报 PPT

```text
使用 $ellen-design-system，把[项目材料路径]整理成一份 5 页、16:9 的项目汇报 PPT。

受众：面试官
传播目标：在 3 分钟内讲清问题、产品判断、方案和评测结果
输出格式：可编辑 PPTX
风格强度：克制版
主色：珊瑚红，分析蓝作为辅助色
必须使用：编号章节、证据卡、原始材料截图
不要使用：大面积装饰、过多贴纸、无法验证的数字

要求：
- 每页只表达一个重点；
- 截图作为证据标本呈现，并附来源说明；
- 标题、正文、卡片和图表保持可编辑；
- 材料没有真实评测数据时，在结果页明确标注待补；
- 加入适合 3 分钟讲述的演讲者备注。
```

## 可复制示例：作品集网页

```text
使用 $ellen-design-system，把[项目内容或现有网页路径]制作或改版成响应式作品集案例页。

受众：AI 产品经理招聘方
传播目标：让招聘方快速判断问题价值、个人贡献、关键决策和证据
输出格式：可运行的响应式网页
风格强度：标准版
主色：分析蓝与珊瑚红
必须使用：项目编号、决策说明、证据卡、结果或待验证状态
不要使用：玻璃拟态、霓虹渐变、无意义动效

要求：
- 优先复用 assets/ellen-tokens.css；
- 桌面端与移动端都保持清晰阅读顺序；
- 拼贴装饰不得遮挡交互控件；
- 保留键盘焦点、对比度和减少动效模式；
- 完成后在常见桌面与手机宽度检查页面。
```

## 可复制示例：审核现有作品

```text
使用 $ellen-design-system，审核[图片、PPT、网页或文件路径]是否符合 Ellen 风格。

请依次给出：
1. 最符合系统的三个部分；
2. 偏差最大的三个部分；
3. 成本最低但影响最大的修改；
4. 色彩、字体、拼贴、证据层级和可读性评分；
5. 如需改版，给出一份可以直接执行的修改清单。

不要只评价“好不好看”，要说明每个判断对应的设计系统规则。
```

## 调用方式

在新任务中直接写 `$ellen-design-system`，然后粘贴任一模板即可。也可以只用自然语言描述任务；当请求明确提到 Ellen 风格、编辑式田野笔记或匹配 AI 产品经理作品集时，本 Skill 可以自动触发。
